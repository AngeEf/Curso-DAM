1. Создание окна с базовыми панелями и метками (JFrame, JPanel, JLabel)
Этот код создает простое окно, разделенное на четыре цветные панели, в каждой из которых находится текстовая метка.
2. Использование массивов для генерации сеток интерфейса (EjemploMatrices)
Вместо того чтобы создавать каждую панель вручную, этот код использует двумерные массивы и вложенные циклы for для создания сетки 2x2.
3. Многострочный текст и кнопки (JTextArea, JButton) - (EjemploBotones)
Пример создания текстовой области для многострочного вывода и кнопок, к которым привязаны слушатели событий.
4. Настройка цветов компонентов и случайная генерация
Пример работы с классом Color (включая создание собственных RGB-цветов) и использование Math.random() для случайного выбора.

Практика
1. Динамический ввод и набор текста через кнопки (виртуальная клавиатура / стенография) - Principal2
2. Счётчики кликов и числовые накопители - JBoton + Escuchar2
3. Отслеживание истории кликов: координаты («Último», «Penúltimo», «Antepenúltimo») - ExamenMatriz
4. Случайная генерация чисел и многострочное форматирование матрицы - GeneradorMatrizAleatoria
