что значит вот эты строка - "%-5s %-15s %-10s\n"
Давайте разберем её на части. Каждое выражение начинается со знака процента %:
<> %-5s — это место для первого слова (например, "ID").
<> %-15s — место для второго слова (например, "Marca").
<> %-10s — место для третьего слова (например, "Longitud").
<> \n — это невидимый символ "переход на новую строку" (Enter).

А теперь разберем, что значит каждый символ внутри самого выражения, например %-15s:
<> % — говорит Java: "здесь будет вставлена какая-то переменная".
<> - (минус) — означает выравнивание по левому краю. Если убрать минус, текст прижмется к правому краю колонки.
<> 15 — означает, что под это слово выделяется ровно 15 символов (ширина колонки). Если слово короче (например, "Nike" — 4 буквы),
Java автоматически добавит 11 пробелов после него.
<> s (от слова String) — означает, что вставляемые данные нужно воспринимать как текст (строку).

## Универсальное чтение таблицы через ResultSetMetaData - leerUniversal
В методичке этот способ используется в базовом методе Leer(), чтобы вывести любую таблицу без ручного перечисления названий столбцов.
### Как это работает: 
getColumnCount() узнаёт число столбцов в выборке, 
getColumnName(n) возвращает имя каждого столбца, 
rs.getObject(n) считывает значение ячейки независимо от её типа данных.

## Проверка значений NULL через wasNull() - leerConControlDeNulos
При чтении числовых полей (getInt, getDouble) JDBC возвращает 0 или 0.0, даже если в таблице записан NULL. 
Метод wasNull() проверяет, было ли последнее прочитанное поле пустым в базе данных.
Важно: вызывать rs.wasNull() нужно сразу после rs.get...() для конкретного столбца, до чтения следующего поля.

## Обработка взаимоблокировок (SQLTransactionRollbackException) - actualizarConReintentos
Если два процесса одновременно пытаются изменить одну и ту же строку, возникает взаимоблокировка (interbloqueo). 
В курсе она решается циклом повторных попыток с паузой Thread.sleep()

## Копирование столбцов из БД в одномерные массивы Java - leerEnArrays
В задачах на повторение требуется считать данные в массивы фиксированной длины, вывести их, обновить таблицу в БД, 
снова перезаписать массивы и вывести повторно
### Как это работает: 
счётчик i синхронно заполняет ячейки всех трёх массивов при каждом проходе rs.next(), 
а проверка i < 5 защищает от выхода за границы массива ArrayIndexOutOfBoundsException
