что значит вот эты строка - "%-5s %-15s %-10s\n"
Давайте разберем её на части. Каждое выражение начинается со знака процента %:
<> %-5s — это место для первого слова (например, "ID").
<> %-15s — место для второго слова (например, "Marca").
<> %-10s — место для третьего слова (например, "Longitud").
<> \n — это невидимый символ "переход на новую строку" (Enter).

А теперь разберем, что значит каждый символ внутри самого выражения, например %-15s:
<> % — говорит Java: "здесь будет вставлена какая-то переменная".
<> - (минус) — означает выравнивание по левому краю. Если убрать минус, текст прижмется к правому краю колонки.
<> 15 — означает, что под это слово выделяется ровно 15 символов (ширина колонки). Если слово короче (например, "Nike" — 4 буквы),
Java автоматически добавит 11 пробелов после него.
<> s (от слова String) — означает, что вставляемые данные нужно воспринимать как текст (строку).
